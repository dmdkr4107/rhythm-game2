# 리듬게임 (rhythm-game2)

음악의 리듬에 맞춰 입력하며 즐기는 리듬게임을 개발하기 위한 프로젝트입니다.

## 현재 상태

**아직 게임 구현 전이며, 프로젝트를 준비하는 단계입니다.**

현재 저장소에는 프로젝트 소개와 AI 작업 하네스 문서가 포함되어 있습니다. 실행 가능한 게임이나 설치·실행 방법은 아직 제공하지 않습니다.

## 개발 방향

음악과 플레이어 입력을 연결하는 리듬게임 경험을 목표로 합니다. 구체적인 게임 규칙, 기능, 사용 기술은 개발 과정에서 결정하고 이 문서에 업데이트할 예정입니다.

## AI 작업 하네스

하네스는 AI가 작업할 때 따를 규칙, 개발 계획, 확인 항목을 모은 문서입니다.

| 문서 | 역할 |
| --- | --- |
| [AGENTS.md](AGENTS.md) | 한국어 설명, 작은 단위 작업, 안전한 변경과 결과 보고를 위한 AI 작업 규칙 |
| [docs/PLAN.md](docs/PLAN.md) | 미정 사항, 기획 질문과 단계별 개발 계획 |
| [docs/CHECKLIST.md](docs/CHECKLIST.md) | 게임 구현 후 실제 동작을 확인할 항목과 결과 기록 |

### 사용법

1. 작업 시작이나 재개 전에 기존 파일과 위 세 문서를 읽습니다.
2. AI에게 작업 범위를 구체적으로 요청합니다. 현재는 문서 준비 단계이며 게임 구현은 별도 요청 후 시작합니다.
3. 플랫폼, 개발 도구, 조작 키, 노트 방식, 음악은 아직 미정입니다. `docs/PLAN.md`의 질문에 답한 뒤 결정 내용을 기록합니다.
4. 구현을 요청한 뒤에는 기능을 작은 단위로 진행하고 `docs/CHECKLIST.md`로 실제 동작을 확인합니다. 구현 전 항목이나 확인하지 않은 항목은 완료로 표시하지 않습니다.
5. 작업 보고에서 실제 확인 결과와 미확인 항목을 구분하고 문서 간 모순을 별도 검토합니다. 커밋, push, 외부 업로드는 사용자가 해당 작업을 요청했을 때만 합니다.

예시 요청: “기획 질문을 함께 정리해줘. 플랫폼과 도구는 아직 확정하지 말고, 게임 구현이나 커밋은 하지 마.”
